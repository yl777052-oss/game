# Snake Game 🐍

簡單的 HTML + CSS + JavaScript 貪吃蛇遊戲。

## 功能
- 分數系統
- 碰撞判定
- 重新開始按鈕
- 鍵盤方向鍵控制

## 使用方式

1. 下載專案
2. 打開 `index.html`
3. 開始遊玩
